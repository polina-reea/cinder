# Кино на двоих 🎬

Тиндер для фильмов: двое свайпают фильмы каждый со своего телефона, а когда оба лайкнули один и тот же — «Мэтч!». Сделано, чтобы мы с парнем перестали по полчаса выбирать, что посмотреть вечером.

<img src="docs/screenshot.png" alt="Карточка фильма" width="320">

## Что умеет

- **432 фильма с рейтингом IMDb 7+** (388 в колоде, остальные мы уже посмотрели — они в `HIDDEN`) — классика, новинки, азиатское и европейское кино, советские комедии, мультфильмы. У каждого — русское и оригинальное название, год, длительность, жанры, актёры, режиссёр и короткое описание.
- **Свайпы** вправо/влево (или кнопки и стрелки ← → на клавиатуре), отмена последнего свайпа, перемешивание колоды.
- **Мэтчи** — общий список фильмов, которые понравились обоим, и кнопка «Выбрать за нас».
- **Фильмы, которые уже лайкнул партнёр, показываются первыми** — так мэтчи находятся быстрее.
- **Фильтры** по жанрам, годам, длительности и рейтингу.
- **«Уже смотрели»** — убирает фильм из колоды у обоих.
- **«Подробнее»** — развёрнутая карточка с подробным описанием без спойлеров.
- **Добавление своих фильмов** с автозаполнением по названию.
- Светлая и тёмная тема, адаптирована под телефон.
- **PWA**: ставится на экран «Домой» как приложение, открывается без адресной строки и работает офлайн.

## Как это устроено

Приложение — одна HTML-страница без фреймворков и сборщиков (чистый JS + CSS). Изначально оно сделано как **артефакт в [Claude](https://claude.ai)** и использует его встроенные возможности:

| Возможность Claude | Для чего |
|---|---|
| `db` | общая база: свайпы обоих, добавленные фильмы, «уже смотрели», подробные описания |
| `user` | кто открыл страницу (владелец видит партнёра, гость — владельца) |
| `sample` | автозаполнение карточки фильма и подробные описания |

**Вне Claude** (например, на GitHub Pages) страница работает в локальном режиме: свайпы хранятся в браузере, а мэтчи считаются через обмен короткими кодами на вкладке «Мэтчи». Автозаполнение, подробные описания и добавление фильмов там недоступны.

## Структура

```
src/
  template.html   разметка, стили и логика приложения
  films.js        база фильмов: [название, оригинал, год, минуты, IMDb, жанры, описание]
  cast.js         режиссёры и актёры по id фильма
  sw.js           service worker (шаблон, версию подставляет сборка)
build.py          сборка: src → index.html + manifest.webmanifest + sw.js (или dist/artifact.html для Claude)
index.html        собранная страница — её и открывает GitHub Pages
manifest.webmanifest, sw.js   PWA (генерируются build.py)
icons/            иконки приложения
posters/          постеры <id>.jpg (372 шт., собраны с Википедии)
avatars/          a.jpg и b.jpg — наши фото (a — кого видит владелец, b — кого видит гость)
```

## Запуск

```bash
python3 build.py          # собрать index.html
open index.html           # открыть в браузере
```

PWA работает только по `https` (или `localhost`), поэтому для проверки установки используйте локальный сервер: `python3 -m http.server` и откройте http://localhost:8000.

### Установка на телефон

1. Включите GitHub Pages: **Settings → Pages → Branch: main / (root)**.
2. Откройте ссылку `https://<ваш-логин>.github.io/<репозиторий>/` на телефоне.
3. **iPhone (Safari):** «Поделиться» → «На экран „Домой“». **Android (Chrome):** меню ⋮ → «Установить приложение».

После первого открытия приложение работает без интернета, а постеры кэшируются по мере просмотра. Когда вы пересобираете и пушите новую версию, приложение обновится при следующем запуске.

Чтобы опубликовать как артефакт в Claude: `python3 build.py --artifact` и опубликовать `dist/artifact.html` с возможностями `db`, `user` (scope `profile`) и `sample`, а постеры — отдельными файлами `posters/<id>.jpg`.

### Настройка под себя

- **Имена и фото пары** — в `src/template.html`, объект `PEOPLE` (имя, творительный падеж для «Вместе с …»). Фото — `avatars/a.jpg` и `avatars/b.jpg`; если их убрать, будут инициалы.
- **Скрыть фильмы, которые уже видели** — `HIDDEN` в `src/template.html` (сейчас там наш список).
- **Добавить фильмы** — только в конец массива в `src/films.js` (id фильма = его позиция в массиве, на нём держатся сохранённые свайпы).
- **Постеры** — `posters/<id>.jpg`, подхватываются при сборке автоматически.

## Важно

- Рейтинги IMDb указаны приблизительно, на момент сбора данных (2026).
- Постеры взяты из Википедии и принадлежат правообладателям фильмов; у 18 фильмов вместо постера цветная заглушка.
- Описания фильмов написаны для этого проекта.
